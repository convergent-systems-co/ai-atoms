# Security — ai-atoms

## Reporting security issues

Report security vulnerabilities to: **security@convergent-systems.co**

Do not open a public GitHub issue for security vulnerabilities.

## Scope

Security issues in scope include:
- Vulnerabilities in hook implementations that could be exploited when deployed
- Schema weaknesses that allow malicious atoms to pass validation
- Supply-chain issues in CI/CD workflows
- Credentials or secrets accidentally committed to this repository

## Response

We aim to acknowledge reports within 48 hours and provide a remediation timeline within 7 days.
